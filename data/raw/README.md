# Raw Dataset

This folder is populated by running `../group_pipeline.ipynb` (or any of the notebooks in `../notebooks/`,
which load the same source): the assigned MNIST dataset is downloaded via
`tensorflow.keras.datasets.mnist.load_data()` on first run, and `group_pipeline.ipynb` additionally caches a
raw copy here as `mnist_raw.npz` (uncompressed train/test images and labels, exactly as provided, before any
preprocessing).

It is intentionally left empty in this template/submission bundle rather than shipping the ~11 MB binary
directly, since it is trivially regenerated by running the notebook once with an internet connection.

To populate it: open `group_pipeline.ipynb`, run all cells top to bottom, and `mnist_raw.npz` will appear in
this folder.
